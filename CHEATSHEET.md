# Regime — как читать

Шпаргалка к индикатору. Подробности и цифры симуляции — в `README.md`.

## Строка состояния

```
k12   ER 2.24   RR 1.23   ▲ безоткатно   [0.29…1.86] авто
 │       │         │            │              │        │
 │       │         │            │              │        └ пороги посчитаны по инструменту
 │       │         │            │              └ действующие пороги главной метрики
 │       │         │            └ вердикт: ▲ безоткатно / ▼ запил / · нейтрально
 │       │         └ размах старшей свечи
 │       └ безоткатность хода
 └ окно: 12 баров графика = одна «старшая свеча»
```

Вердикт всегда по **главной метрике** — первой включённой (по умолчанию ER).
Пометки `авто` нет → либо режим «Вручную», либо калибровка не удалась
(в окне меньше 20 значений: короткая история, только что сменили символ).
Нет чисел `ER`/`RR` → метрика не определена: истории меньше `k+1` баров
или цена в окне не двигалась вовсе.

## Шкала

| Значение | Смысл |
|---|---|
| **1.0** | случайное блуждание — сплошная горизонталь на панели |
| **выше 1** | движение упорядочено: идёт, не возвращаясь |
| **ниже 1** | путь длинный, прогресса нет |
| **потолок √k** | k=6 → 2.45, k=12 → **3.46**, k=24 → 4.90 |

Направление метрики не различают: тренд вверх и вниз дают одно число.

## Три метрики

| | Что меряет | Скорость | Ложных на шуме |
|---|---|---|---|
| **ER** толстая | по закрытиям: чистый ход / длина пути | 4–6 баров | 36 % при пороге 1.20 |
| **RR** тонкая | по диапазону: размах старшей / сумма младших | ≈ то же | 27 % |
| **VR** пунктир | то же, но усреднённое по десяткам окон | 25–30 баров | 6 % |

ER — быстрая и шумная, VR — медленная и надёжная. Размен неустранимый.
Автопороги (15/85) не делают ER надёжнее, они лишь приводят долю подсветки
к заказанной: горит на 15 % самых упорядоченных и 15 % самых пильных баров.

## Главное: комбинация ER и RR

| ER | RR | Что на цене | Что делать |
|---|---|---|---|
| высокий | высокий | **чистый импульс** — крупные бары в одну сторону, перекрытий мало | по тренду, стоп за откат |
| высокий | средний/низкий | **грайнд** — закрытия ступеньками, но бары широкие: направление держится, внутри мотает | по тренду, но стоп за размах бара, не за прогресс |
| низкий | высокий | **качели** — сходили далеко и вернулись. Волатильность есть, направления нет | самое опасное место; контртренд от краёв либо вне рынка |
| низкий | низкий | **вялый флет** — узко и никуда | ждать |

Предельный случай для проверки интуиции: если закрытия растут на `d` за бар,
а внутри бара размах `R ≫ d`, то ER = √k (максимум), а RR = 1/√k (минимум).

## Заливка и подсветка

- **Панель**: столбики между главной линией и уровнем 1.0. Зелёные выше
  верхнего порога, красные ниже нижнего, нейтральная зона не закрашена.
- **Фон строки состояния** красится в цвет режима — только когда режим не нейтральный.
- **Regime Shade** (отдельный индикатор) — те же зоны полосами на графике цены.
  Источник «ER и VR — когда согласны»: быстрая задаёт момент, медленная
  отсекает выбросы. Лучший режим для бинарного «сейчас точно не шум».

## Чему не верить

- **Одному бару.** У ER на шуме ст.отклонение 0.72 — отдельный выброс ничего
  не значит. Читайте линию формой, глаз усредняет лучше порога.
- **Большому k как признаку надёжности.** Разброс ER не падает с ростом k
  (0.69 / 0.72 / 0.74 / 0.75 для k = 6 / 12 / 24 / 48): числитель — одно
  смещение за окно, одна реализация. Большое k только замедляет.
- **Секундным всплескам.** Движение на 1–1.5 с внутри минутного бара не видно
  в принципе. Для этого SpikeVoiceover либо Regime на тиковом графике.

## Быстрая настройка

| Хочу | Крутить |
|---|---|
| подсветка горит слишком часто | процентили 10/90 или 5/95 |
| слишком редко | 25/75 |
| реагировать быстрее | k меньше (6–8); надёжнее не станет, только быстрее |
| другой горизонт | k = во сколько раз старше: M5 k=12 ≈ час, M1 k=15 ≈ четверть часа |
| подтверждение, что не шум | включить VR, глубина 96–192 |
| меньше дёрганья линии | сглаживание EMA 3–5 баров |
